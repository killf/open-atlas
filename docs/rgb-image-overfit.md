# 干净 RGB 预测与单轨迹过拟合

本轮先调整输出参数化，再执行单条训练轨迹 8 帧的记忆能力检查。深度不参与输入、目标、损失或输出；没有图像编码器、VAE 或预训练权重。相机条件保留。

## 模型与输入输出

骨干沿用 4 层、128 维、4 个注意力头的 DiT 风格模型；64×64 图像采用 4×4 patch，每帧 256 个 token。默认历史为首帧与最近帧，输入仍是历史 RGB、历史／目标相机射线、视频时间差，以及目标的加噪图像和扩散时间。

调整点是网络直接输出干净下一帧 RGB `I_hat`，随后转换为速度；最终调制层也按 DiT 参考实现零初始化。参数量保持 1,327,920。没有增加深度分支或额外解码器。

依据 [JiT 原论文](https://arxiv.org/html/2511.13720v1) §3、§4.3 和 [作者代码](https://github.com/LTH14/JiT/blob/cbc743a2ada5e9762697da2c83f8c4f8379e8c17/denoiser.py)，采用：

```text
x_t = (1-t) * noise + t * I
D = max(1-t, 0.05)
I_hat = model(x_t, t, history, cameras, video_times)
v_hat = (I_hat - x_t) / D
v_target = (I - x_t) / D
loss = mean((v_hat - v_target)^2)
```

两端使用相同分母，等价于按 `1/D²` 加权的图像误差。因此接近 t=1 时，预测等于真值仍有零损失；不能只截断预测速度的分母而保留未截断的速度目标。训练时间仍从 [0,1) 均匀采样，没有照搬 JiT 全部训练配方。

采样从高斯噪声开始，用 `v_hat` 做 Euler 积分，最后一次直接取干净图像预测，再裁剪 RGB 到 [0,1]。这一步避免高采样步数时分母保护保留噪声残差；默认 20 步下与末次 Euler 更新数学等价，不增加网络调用。网络输出干净图像不意味着一次前向的视频回归。目标相机仍由外部指定。检查点格式升级为 4，并保存 `parameterization=clean_rgb`；旧格式 3 的速度模型明确拒绝加载，避免相同三通道形状被错误解释。

这属于用户指定的像素空间简化，与 Atlas 官方潜空间方案存在差异。来源与已知边界见 [一手资料核对](atlas-source-audit.md)；此前速度版及其独立场景指标见 [历史记录](rgb-next-frame.md)。

## 方案 1：固定 8 帧

```bash
python -u -m open_atlas.overfit \
  --trajectory data/rendered/replica_rgb_v2/train_view_0/apartment_0_truck_000/transforms.json \
  --output runs/rgb-image-overfit-v1 \
  --frames 8 --steps 1000 --image-size 64 --sampling-steps 20 \
  --seed 42 --device cpu
```

命令要求新的输出目录。仅接受 `split=train` 的轨迹，复制前 8 张 RGB 和对应相机，产生 7 个下一帧目标；原始文件不变，也不复制深度。子集及 RGB SHA256 清单保存在输出的 `data/` 与 `manifest.json`。

从随机初始化开始训练；默认 patch 4、dim 128、4 层、4 个头、两帧上下文、batch 最大 4、AdamW 3e-4、CPU 2 线程。7 个目标组成每轮两个批次（4、3），1000 步对应 500 次完整遍历。此实验不使用验证或测试场景。

训练后逐目标提供真实历史，只生成紧接的一帧；噪声种子为 0、1、2，各生成 7 张图像。每个目标都重新使用真实历史，不把预测反馈给下一目标。指标在原始 64×64 分辨率计算；基线复制真实上一帧，区别于此前自由滚动实验的复制首帧基线。

`metrics.json` 汇总三个种子的全部像素误差，报告 PSNR／MAE、各种子指标和复制上一帧基线。预先规定检查条件：汇总 PSNR 至少 30 dB，并比基线高至少 3 dB；还须查看各种子结果，判断稳定性。预测图像保存在 `predictions/seed_*/`。

这是训练集记忆检查，不能作为新轨迹或新场景泛化结果，也不构成与旧速度模型的受控消融。

## 验证

31 项测试通过：干净图像预测在 1／4／20／80 步的解析采样、图像误差在速度空间的权重、干净端点的有限零损失、旧检查点拒绝加载、无深度训练、无未来真值推理、相机条件，以及单轨迹截取和解析复制基线等。
