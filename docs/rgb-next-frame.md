# RGB 下一帧任务与 Atlas 原文对照

本版本按用户明确约束，仅训练下一帧 RGB。此前 RGBD 联合训练、视频深度重建计划均由这个约束替代。深度文件即使保留在数据目录中，也不参与当前数据加载、损失或评测；模型没有深度输出头。

## 公开事实与实现边界

主要依据为 [Atlas 官方技术文章](https://www.worldlabs.ai/blog/atlas) Model Architecture 部分、[DiT 论文](https://arxiv.org/abs/2212.09748)第 3 节，以及 [Rectified Flow 论文](https://arxiv.org/abs/2209.03003)。Atlas 未公开完整网络或训练数据配方，以下不是官方实现声明。

| 原文机制 | 当前实现 | 范围与取舍 |
| --- | --- | --- |
| 多模态序列按元素自回归 | 给定历史 RGB 与相机，生成下一张图像潜变量 | 只实现 RGB／相机任务，不复现文本或深度模态 |
| 图像／视频元素具有相机条件 | 潜变量附加 Plücker 射线，相机相对第一参考帧 | 目标轨迹为外部条件，不由模型预测 |
| 潜空间扩散 | 冻结 TAESD 编码 RGB，在图像潜空间训练、采样、解码 | Atlas 编码器未知；TAESD 是轻量替代，不是其官方 VAE |
| Rectified Flow | `z_t=(1-t)*noise+t*z_next`，回归 `z_next-noise` | 每次只计算下一帧图像潜变量 MSE，无深度损失 |
| Transformer | 小型 DiT、adaLN-Zero 条件调制 | adaLN-Zero 来自 DiT 主实验配置，不能断言 Atlas 使用相同块 |
| 时空建模能力 | 提供历史到目标的时间差，区分视频时间与扩散时间 | 现有数据只有静态场景与相机运动，不验证物理模拟 |

“下一帧预测”描述的是生成任务；生成该帧内部仍通过 rectified-flow 去噪，不是一次前向直接回归 RGB，也不是离散像素分类。官方支持 RGB 输入、深度输出，不意味着其预训练必定仅使用 RGB。RGB-only 是本项目的训练范围。

## 数据与坐标

数据集只索引 `rgb`、`K`、`c2w`、时间与划分字段。每个目标为紧接可见历史之后的一帧，默认从历史中选取第一帧和最近一帧；不存在目标或未来图像作为条件。训练始终使用干净历史，这仍不是 Diffusion Forcing。

相机编码使用 `inverse(T_world_from_first) @ T_world_from_camera`。这一相对坐标选择参考 [CAT3D](papers/cat3d-2405.10314.pdf)第 3.1 节，统一改变世界坐标不会改变输入射线。输出元数据仍保存原始场景相机变换。

训练、验证、测试分别使用 apartment_0／apartment_1／apartment_2，60 段视频共 1392 张 RGB，1104／90／138 个目标。保留历史数据清单与合成机位，未重新采集测试集或改动其目标图像。

## 图像编码器

采用 [madebyollin/taesd](https://github.com/madebyollin/taesd) 的 SD1/2 图像编码器和解码器，固定提交 `d968ebf70e930b76243c773a63162ed94482361f`。仅保留所需架构，MIT 署名见 [许可文件](asset-licenses/TAESD.txt)。两份权重由 `scripts/download_codec.py` 下载并检查固定 SHA256。

RGB 范围为 [0,1]，64×64 图像压缩为 4×8×8 连续潜变量。四个通道均为学习到的图像特征，不具有 RGBD 通道含义。使用作者的原始潜变量尺度，不做 RGB 范围裁剪；解码器输出再裁剪到 [0,1]。

编码器和解码器全程冻结，不加深度或额外编码器训练目标。缓存按各自 split 编码 RGB，不混用训练／验证／测试图像。推理历史使用已生成潜变量，避免反复编解码。检查点包含冻结编码器权重，推理可独立运行。

TAESD 是确定性轻量自编码器，存在细节损失与逐帧闪烁风险，不能用它代表 Atlas 未公开的编码器或声称完整 VAE 复现。

## 验证和小规模训练

新增回归要求：删除所有深度文件与字段后可训练；目标是下一帧 RGB；整体变换世界坐标不改变射线；编码器权重训练前后完全相同；移除全部未来图像后同种子生成相同结果；评测基线与解析计算一致。

本轮训练固定 1000 步，64×64 图像、8×8 潜变量、4 层、128 维、4 个头、batch 4、AdamW 3e-4、种子 42、CPU 2 线程。验证流损失使用独立场景与固定噪声；它不代替最终 RGB 自由滚动评测。

评测每段只给首帧真实 RGB，Euler 20 步自由滚动，统一缩放到 32×32 评分。PSNR 从所有像素的平方误差汇总计算，图像范围 [0,1]；同时报告重复首帧基线和 RGB MAE。结果仅代表此单场景小模型，不声称超过 Atlas 或完成空间智能复现。

## 本轮实际结果

1000 步 CPU 训练已完成，DiT 可训练参数为 1,280,516。27 项测试全部通过；编码器在真实 RGB 上的编码／解码与作者原代码逐元素完全相同。本轮训练数据目录没有深度文件和字段。

| 相同 32×32 评分下的测试项 | 结果 |
| --- | ---: |
| 当前 RGB-only 潜空间模型，1000 步 | PSNR 11.37 dB |
| 历史 RGBD 像素模型，6000 步 | PSNR 11.03 dB |
| 重复首帧 RGB 基线 | PSNR 17.00 dB |
| 当前模型 RGB MAE，[0,1] | 0.2073 |

测试是独立 apartment_2 场景的 6 条轨迹、138 个生成目标，每段只提供首帧真实 RGB。不同模型的训练步数、编码器和结构均不同，以上只作历史参照，不是受控消融。当前结果仍低于复制首帧基线，不足以证明新视角生成质量有效，更不能声称复现 Atlas 指标。训练流损失从像素空间变为潜空间后，数值不能与旧版本直接比较。

检查点在 `runs/rgb-next-frame-v1/last.pt`，日志为同目录 `train.log`；生成视频和逐轨迹评测位于 `outputs/rgb-next-frame-v1-eval/`。完整命令、数据与编码器哈希和指标见 [结构化记录](rgb-next-frame-results.json)。下一轮应使用验证集确定方案，并优先增加独立训练场景；不根据这一次测试结果反复调参或增加同场景步数。
